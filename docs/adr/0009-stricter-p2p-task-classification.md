# ADR-0009: 收紧私聊自动建群判定（去掉纯长度兜底）

- 状态: accepted
- 日期: 2026-07-28
- Supersedes: ADR-0006 中「≥20 字长消息兜底算任务」这一条；其余升级流程不变

## 背景（Context）

ADR-0006 用 `LooksLikeTask` 在私聊识别「明确任务」后自动建群。其中
**≥20 字即视为任务** 的兜底过松：用户发联调/测试话术
（如「都可以，我在进行测试，你触发下 ask 交互，快」约 22 字、无动作词）
也会被升级建群，违背「闲聊留在私聊」与「用户未表达建群意图」。

误建群的代价高于误留在私聊（多一个无关群 + 打断当前测试链路）。

## 选项（Options）

1. 提高阈值（如 50/80 字）— 仍会误伤略长的闲聊/联调句。
2. 去掉纯长度兜底，仅「附件」或「动作关键词」算任务 — 更可预期。
3. 引入 LLM 分类 — 延迟与成本，且仍可能误判。

## 决策（Decision）

选 **2**。

`LooksLikeTask` 仅在以下情况为 true：

1. 带附件（图片/文件）；或
2. 文本命中既有 `taskKeywords`（帮我 / 修复 / implement / …）。

完全匹配的 `smalltalk` 短句仍优先排除。不再用消息字数兜底。

用户需要建群时：说带动作词的任务，或显式 `/new chat`。

## 理由（Rationale）

- 可测试、零延迟；与「未表达建群意图就不建」一致。
- 误判方向：宁可在私聊答完，也不要静默拉群。

## 后果（Consequences）

- 长文任务描述若不含动作关键词，会留在私聊（可再发「帮我…」或 `/new chat`）。
- ADR-0006 的建群流程、15s 跟发窗口、绑定例外、降级逻辑保持不变。
