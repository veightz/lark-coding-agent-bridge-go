3.3 PiAdapter / Oh My Pi（omp） internal/agent/pi.go（常驻 RPC，每 scope 一进程）

CLI 定位：共享 agentCommand 启动层先查进程 PATH，再查 Volta、~/.local/bin、Bun、npm、pnpm、Homebrew 等常见用户级目录。因此 launchd 的精简 PATH 不会导致已安装的 pi/omp 无法启动；显式 binary 路径保持不变。
